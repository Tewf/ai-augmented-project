## Conventions

- No em dash or en dash in prose. Use a comma, a colon, parentheses, or a hyphen for ranges.
- A grade moves only with a cited source, and a number read from an abstract is marked secondary.
- Public text names no tool that wrote it and no local path.

## Precedence

When this file or a memory disagrees with the code, follow the code and say so.

## Pointers

- A new principle: read `principles/session/code-takes-precedence.md` and `AGENTS.md`.
