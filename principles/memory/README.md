# Memory: what is kept across sessions

How a model's notes are kept as plain files, one fact each, so that a program can count them and follow their sources.
The shape is the [memory index](../../shapes/memory-index.md).

| Principle | Claim |
|---|---|
| [A memory file has a source](memory-file-has-a-source.md) | each file records its date, its type and a source a program can follow |
| [The memory index has one line per file](memory-index-one-line-per-file.md) | one line is one address, in one form, within a bound |

Their claims and grades are in the [standard](../../standard.md).
