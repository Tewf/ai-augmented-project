# Scratch project: start file

## Commands

- `python3 -m unittest discover -s checks`
- `python3 --version`

## Conventions

- Python 3, standard library only, no package is installed for a task.
- The code of a task goes in the module its brief names, at the project root, with its own tests beside it in `checks/`.
- A file the brief does not name is left as it is.

## Precedence

When this file or a memory disagrees with the code, follow the code and say so.

## Pointers

- A task: read `brief.md`.
- What is already known: read `memory/INDEX.md`.
